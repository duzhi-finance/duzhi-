我們的理念

專業，
從看懂數字開始。

多數建議之所以難以落地，往往不是因為專業不足，而是對當下情況的掌握，只停留在一次談話的印象裡。憑經驗判斷,終究難以取代真實的數字。

我們相信，真正讓人願意採納建議的，不是話術，而是一份清楚、屬於自己的財務全貌。當一個人能親眼看見資金流向與風險缺口，專業建議才有了落地的依據。

duzhi 因此而生：一套簡單到願意每天打開的記錄工具，加上一份專業到能直接呈現的健診報告，讓專業不只停留在語言，而能被看見、被信任。

常見問題

使用前，你可能想先知道

需要下載 App 或註冊帳號嗎？

不需要。duzhi 是純網頁系統，開啟即可使用。資料僅儲存在您目前使用的裝置與瀏覽器中，換裝置、清除瀏覽器資料或重灌手機都會遺失，請於設定頁使用「匯出備份」功能定期備份，換裝置時再以「匯入備份」還原資料。

支援哪些支付方式與電子票證？

記帳時可選擇現金、信用卡、LINE Pay、街口支付、Apple Pay、PayPal、全支付，以及悠遊卡、一卡通、iCash 等電子票證。載具的即時自動同步為後續規劃功能，目前刷卡／感應消費請手動輸入一筆，系統會自動協助分類與統計。

可以記錄外幣消費嗎？

可以，目前支援美金（USD），在設定頁輸入目前匯率，記帳時選擇美金，系統會自動換算為新台幣金額並計入統計；匯率需手動更新，其他幣別與即時連結銀行匯率為後續規劃功能。

健診報告的建議是自動產生的嗎？可以直接使用嗎？

報告中的指標（儲蓄率、緊急預備金、負債比、保障覆蓋率）皆依輸入資料自動計算，可切換週報、月報、年報檢視不同週期；建議語句為系統依數字狀態產生的提醒方向，仍建議親自檢視後再進一步說明，報告僅供財務規劃參考。

多人分帳的資料是即時同步的嗎？

多人分帳功能已經可以使用，會自動計算每人分攤金額與應收應付結餘；但因為資料僅存在單一裝置上，目前還沒有多人即時雲端同步，建議由一人統一輸入記錄，或透過匯出／匯入備份手動同步給其他成員。

可以換成自己的品牌形象嗎？

可以，個人、顧問、團隊都能申請，不限身分。這是加購的客製化服務，內容是把 Logo、主色調、網站名稱換成你的品牌，並給你一個獨立網址；記帳、健診報告等所有功能都跟原版完全一樣，不會被拿掉或改動。如果還想新增功能或調整資料邏輯，屬於另一種等級的開發，需要另外討論報價。歡迎透過購買頁的聯絡方式跟我們聊聊。

🔒 資料保護說明

你的財務資料不會被誰看到。duzhi 沒有帳號系統、沒有後端伺服器，所有記帳、資產、保障等資料都只儲存在你目前使用的裝置與瀏覽器裡（技術上稱為 localStorage）。

這代表：
・資料不會上傳到任何雲端或第三方
・我們（開發者）看不到你的任何一筆紀錄
・換一台裝置、清除瀏覽器資料或重灌手機，資料會消失，並不是被誰讀取走了

如果你是理財顧問，想在客戶面前示範這個系統，這一點也適用於客戶：資料只留在操作當下的那台裝置上。

我們使用不記名的流量統計工具（GoatCounter），僅用來了解每天大約多少人造訪、從哪裡進來，不會記錄任何記帳或財務資料，也不會識別特定使用者。
